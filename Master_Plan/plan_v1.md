## 摘要

本计划面向乳腺癌组织病理图像分类中“标注稀缺、部署受限、临床信任不足”三个现实约束，选择公开数据成熟、基线可复现的 BreakHis 作为主数据集、BACH 作为跨中心外部验证集，研究一种面向小样本场景的轻量化可解释分类方法。研究以患者级划分为实验严谨性底线，以“轻量混合架构 + 不确定性感知门控融合”为核心方法增量：设计局部 CNN 与全局线性复杂度模块的双路轻量编码器，通过样本级不确定性驱动门控权重，实现局部形态特征与全局组织结构特征的动态融合，并由门控权重直接导出与决策过程一致的样本级解释。实验将覆盖全监督患者级基准、5-shot/10-shot 小样本实验、效率对比、消融实验、BACH 两阶段外部验证与跨域校准分析，并采用五折患者级交叉验证、配对统计检验和按放大倍数分层报告。计划在 6 个月内完成从文献调研、基线复现、模型实现、主实验、外部验证到论文初稿的完整流程，形成一篇方法清晰、实验严谨、可投稿 SCI 期刊的论文初稿。

**关键词：** 乳腺癌组织病理；深度学习；小样本学习；轻量化模型；不确定性估计；可解释性；跨域校准

## 一、研究背景与问题

乳腺癌组织病理图像分类是计算病理的经典任务，但临床部署面临三重约束。第一，高质量病理标注昂贵，患者级标注尤其稀缺，小样本与少样本学习因此成为持续热点。第二，高精度模型往往参数量和计算量过大，难以部署到病理工作站或边缘设备。第三，临床使用者不仅需要类别预测，还需要知道“模型有多确定”以及“模型依据什么做出判断”，而现有工作多依赖事后归因（如 Grad-CAM），解释与决策过程存在脱节。

BreakHis 是乳腺癌组织病理分类中使用最广的公开数据集之一，包含 7,909 张显微图像、来自 82 名患者（按 slide ID 去重后 81 个唯一病例），覆盖 40×、100×、200×、400× 四种放大倍数，良性 2,480 张、恶性 5,429 张，并细分为 8 个组织学亚型。BACH 包含 400 张 H&E 图像，四类均衡（正常、良性、原位癌、浸润性癌各 100 张），测试数据来自与训练数据不同的患者集，适合作为跨中心外部验证集。

本研究的核心问题是：**在严格患者级评估下，能否在不显著增加参数量的前提下，通过不确定性驱动的门控融合提升小样本乳腺癌组织病理分类的鲁棒性，并使模型输出的置信度与解释在跨中心域偏移下仍然可用？**

## 二、文献调研计划与研究缺口

### 2.1 调研安排

第 1—2 周完成定向文献调研，目标不是泛读，而是产出一张“研究缺口矩阵”。检索围绕三条线展开：医学图像小样本学习、轻量化病理架构（CNN/Transformer/Mamba）、不确定性建模与可解释性。每篇代表性论文记录“解决了哪个缺口、遗留什么问题、本文如何不同”。

### 2.2 四个研究缺口

**缺口 A：小样本与标注效率。** 病理图像标注成本高，少样本学习是持续热点。FHIST 基准显示，在 CRC-TP → BreakHis 的跨域少样本设置下，ProtoNet 5-shot 仅 40.8% ± 0.49，Finetune 为 56.9% ± 0.52，TIM 为 57.9% ± 0.57；1-shot 下 ProtoNet 仅 32.0%。这说明小样本设置远未饱和，且简单微调仍是强基线。

**缺口 B：高效架构与部署可行性。** 高精度模型往往过大。Patho-LiteDFSNet 以 0.20 M 参数量在患者分层五折下达到 89.1% 准确率、0.920 F1；MSWA-ResNet 以约 11.8—12.1 M 参数量在患者级 70/30 划分下达到 96% 患者级准确率（100×/200×/400×，40× 为 92%）。这两个工作提供了“极致轻量”与“中等参数”两个效率-精度参照点，但“不确定性驱动融合”的效率坐标仍不清晰。

**缺口 C：可解释性与临床可信度。** 现有工作多使用事后归因，解释与融合决策分离。Patho-LiteDFSNet 已使用 Gated Routing + Fusion 模块，说明门控融合在轻量病理架构中有先例；xMagNet 已使用动态放大率感知融合 + Monte Carlo dropout 不确定性量化。因此“不确定性 + 融合”并非空白，真正的缺口是：**不确定性如何内生地参与融合权重计算，并同时服务于跨域校准与可解释性输出**。

**缺口 D：外部验证与校准严谨性。** BreakHis 上大量高准确率来自图像级划分，存在患者泄漏。文献报告，图像级划分下二分类准确率可达 99.6%，切换到患者级后降至 92.1%，患者级聚合后为 93.8%—97.5%。BACH 外部验证中，BreakHis 训练模型零样本迁移的 balanced accuracy 接近随机，特异性极低；冻结 backbone、仅训练分类头后性能才恢复到有意义水平。另有工作报告 BreakHis 95.21% → BACH 92.10%（p=0.018），说明掉点虽小但统计显著。SAFE-MedPath 在严格患者分离下报告 balanced accuracy 0.877、ECE 0.126，并指出染色增强与温度缩放存在 calibration-transfer gap；另一项工作通过温度缩放将 ECE 从 0.072 降至 0.018。跨域校准是明确缺口。

**交付物：** 研究缺口矩阵（附录模板），行是四个缺口，列是 5—8 篇代表性论文，最后一列写“本文切入点”。

## 三、选题定位与研究目标

### 3.1 选题定位

**疾病载体：** 乳腺癌组织病理。选择理由：BreakHis 规模足够支撑患者级主实验与小样本 episode；BACH 是现成的跨中心外部验证集；组织病理的“细胞核形态（局部） vs. 腺体结构（全局）”为门控权重的可解释性提供了直观的视觉锚点，降低了对额外专家标注的依赖。

**方法定位：** 不做“新疾病 + 新模态”的高风险组合，而在成熟数据集上做方法论增量。主实验锁定**患者级二分类（良性 vs. 恶性）**，八分类作为补充或消融，以避免在本身困难的任务上分散时间。

### 3.2 研究目标

1. 构建严格患者级划分的 BreakHis 二分类评估流水线，复现 2—3 个效率-精度参照基线。
2. 提出不确定性感知门控融合的轻量双路架构，在参数量不超过最强基线 1.2 倍、FLOPs 不超过 1.5 倍的约束下，争取患者级二分类准确率进入 92%—96% 区间。
3. 完成 5-shot/10-shot 小样本实验，以 Finetune 和 TIM 为强基线，检验门控融合在标注稀缺时的价值。
4. 完成 BACH 两阶段外部验证（零样本 + 冻结头校准），比较内生不确定性门控与 post-hoc 温度缩放的跨域校准表现。
5. 形成可投稿论文初稿。

## 四、创新点设计

**创新点一（主创新，方法论层）：不确定性内生的门控融合机制。** 针对“高效架构在小样本条件下退化”的问题，设计参数高效的自适应特征融合机制，在局部 CNN 特征与全局线性复杂度特征之间动态加权。与 xMagNet 的事后 MC dropout 不确定性不同，本方法的不确定性 \(u\) 直接参与前向融合权重 \(g=1-u\) 的计算，使融合决策与不确定性估计成为同一过程。与 Patho-LiteDFSNet 的 Gated Routing 不同，本方法的门控信号来源是样本级不确定性，而非纯学习到的路由。

**创新点二（辅助创新，可信度层）：跨域校准分析。** 在 BACH 外部验证中同时报告零样本、冻结头校准、post-hoc 温度缩放三种条件下的 ECE 与可靠性图，检验内生不确定性门控是否比事后校准具有更稳定的校准迁移。文献已指出染色增强和温度缩放存在 calibration-transfer gap，这为“内生不确定性”提供了明确的对照叙事。

**创新点三（辅助创新，可解释性层）：决策一致的样本级解释。** 从门控权重 \(g\) 导出每个样本对局部特征与全局特征的依赖程度，结合不确定性 \(u\) 给出“判断依据 + 可靠程度”的层级化解释。该解释直接来自前向计算，而非事后归因，与模型决策过程一致。

**一句话表述：** 提出一种不确定性门控的轻量双路架构，在严格患者级评估下提升小样本乳腺癌组织病理分类的鲁棒性，并通过跨域校准与决策一致的解释增强临床可信度。

## 五、模型架构安排

### 5.1 基线选择

| 基线 | 作用 | 最低要求 |
|---|---|---|
| ResNet-50 / EfficientNet-B0 | CNN 标准基线 | 患者级划分下复现报告指标 ±1.5% |
| Patho-LiteDFSNet（或其中门控路由结构） | 极致轻量参照（0.20 M / 89.1%） | 统一评估脚本下复现 |
| MSWA-ResNet | 中等参数参照（约 12 M / 96%） | 按放大倍数分层复现 |
| Swin-Tiny / ViT-B/16 | Transformer 基线 | 相同患者级划分下比较 |
| ProtoNet / Finetune / TIM | 小样本基线 | 5-way 5-shot/10-shot 协议一致 |

### 5.2 所提架构

```text
输入病理图像
    ↓
[双路轻量编码器]
  路A：局部特征提取（深度可分离卷积 / 小 kernel CNN）→ F_local
  路B：全局上下文建模（线性复杂度 Mamba 块或轻量 Transformer）→ F_global
    ↓
[不确定性感知门控融合模块] ← 核心创新
  输入：F_local, F_global
  计算：u = σ(MLP([F_local; F_global]))，u 为样本级不确定性
  门控：g = 1 - u（或经温度缩放的软门控）
  融合：F_fused = g ⊙ F_local + (1-g) ⊙ F_global
  辅助输出：u 作为置信度估计
    ↓
[分类头]（轻量 MLP 或线性层）
    ↓
类别预测 + 置信度分数 + 门控解释
```

**设计约束：** 总参数量不超过最强基线的 1.2 倍，FLOPs 不超过 1.5 倍。若超标，优先压缩不确定性 MLP 隐层维度，保留门控核心。

### 5.3 可解释性实现

从门控权重 \(g\) 导出样本级解释：\(g\) 接近 1 表示模型更多依赖局部特征（细胞核形态、核分裂等），接近 0 表示更多依赖全局上下文（腺体结构、组织架构）。结合 \(u\) 给出“该判断的可靠程度”。该解释直接来自前向计算，不额外挂接 Grad-CAM 作为唯一解释。

## 六、数据集与预处理

### 6.1 BreakHis（主数据集）

**规模：** 7,909 张，82 个 slide 记录（按 slide ID 去重后 81 个唯一病例；`14-13412` 的 DC/LC 两个目录属同一病例），40×/100×/200×/400× 四种放大倍数，良性 2,480、恶性 5,429，8 个组织学亚型，700×460 RGB PNG（其中 74 张为 700×456）。

**划分：** 采用患者级五折分层交叉验证：以 slide ID 作为患者标识（`14-13412` 的 DC/LC 两个目录合并为同一病例），同一患者只出现在一个折中；划分文件为 `Dataset/BreakHis/splits/patient_5fold.csv`，由 `cli/build_dataset_splits.py` 以固定随机种子生成，并校验无患者泄漏。报告五折均值 ± 标准差，主表按 40×/100×/200×/400× 分层。

**放大倍数：** 主表按 40×/100×/200×/400× 分层报告，不混合平均，以展示低倍率下的行为。

### 6.2 BACH（外部验证集）

**规模：** 400 张 H&E 图像，正常/良性/原位癌/浸润性癌各 100 张，2048×1536 TIFF，像素尺度 0.42 μm，测试数据来自不同患者集。

**任务对齐：** 映射为二分类：normal + benign → 良性，in-situ + invasive → 恶性，与 BreakHis 良恶性任务语义对齐。在讨论中说明 BACH 恶性类包含两种生物学行为不同的亚型，是额外域偏移来源。

**预处理：** 统一 resize 策略，并同时报告“无染色归一化”与“Macenko/Vahadane 归一化”两种条件，量化掉点来源。

### 6.3 数据卡

## 七、实验设计

### 7.1 实验矩阵

| 实验组 | 设置 | 目的 |
|---|---|---|
| E1 全监督患者级基准 | 100% 训练数据，患者级二分类，按放大倍数分层 | 证明方法在数据充足时不弱于基线，锚定 92%—96% 区间 |
| E2 小样本实验 | 5-way 5-shot / 10-shot，Finetune、TIM、ProtoNet 为基线 | 证明门控融合在标注稀缺时的价值；目标 5-shot ≥60% 为有讨论空间，≥65% 为清晰正向信号 |
| E3 效率对比 | 参数量、FLOPs、推理时间、GPU 显存 | 与 Patho-LiteDFSNet（0.20 M / 89.1%）和 MSWA-ResNet（约 12 M / 96%）形成效率-精度坐标 |
| E4 消融实验 | (a) 去掉门控，固定融合权重；(b) 去掉不确定性估计；(c) 仅用单路编码器 | 隔离每个组件贡献 |
| E5 跨域校准 | BreakHis 内部、BACH 零样本、BACH 冻结头校准；ECE、可靠性图、Brier Score；对比 post-hoc 温度缩放 | 检验内生不确定性门控的校准迁移是否更稳定 |
| E6 鲁棒性与外部 few-shot | 高斯噪声/运动模糊/对比度扰动；BACH 每类 5 张标注微调门控与分类头 | 证明临床场景稳定性与跨域极少标注适配能力 |

### 7.2 BACH 两阶段外部验证

- **阶段一（零样本）：** 如实报告接近随机的 balanced accuracy 和极低特异性，作为域偏移严重程度的量化证据，不隐藏。
- **阶段二（冻结头校准）：** 冻结双路编码器与门控融合模块，仅用 BACH 少量标注样本训练分类头或微调门控温度参数，报告校准后的准确率与 ECE。这是“外部 few-shot 适配”创新点的真正落点。

### 7.3 评价指标与统计检验

- 分类：Accuracy、Macro-F1、AUC-ROC、敏感性/特异性；
- 校准：ECE、Brier Score、可靠性图；
- 效率：参数量（M）、FLOPs（G）、推理延迟（ms/图）；
- 可解释性：门控权重与放大倍数/组织形态的定性一致性分析；若可得专家标注，补充空间一致性指标。

**统计检验：** 五折配对 Wilcoxon 符号秩检验或 Bootstrap 95% CI，报告中位数与置信区间。统计不显著时用效应量和置信区间叙事，不伪造显著性。

## 九、论文撰写计划

### 9.1 论文结构

## 十、可行性分析与风险预案

### 10.1 可行性

- **数据可得性：** BreakHis 与 BACH 均为公开数据集，患者级划分由本项目脚本生成，获取与预处理周期可控（2—3 周）。
- **基线可复现：** Patho-LiteDFSNet 与 MSWA-ResNet 提供了明确效率-精度坐标；FHIST 提供了小样本基线坐标。
- **方法可实现：** 双路轻量编码器与门控融合均为成熟组件，创新点集中在门控信号来源与校准分析，工程风险可控。
- **时间匹配：** 6 个月倒排，关键节点留有与导师同步的窗口（第4周、第9周、第13周）。

### 10.2 风险与应对

| 风险 | 应对 |
|---|---|
| 主创新小样本精度增益不显著 | 转向“效率—校准—可解释性”三角叙事；E3/E5/E6 已为此准备 |
| BACH 零样本接近随机 | 预期结果，如实报告并作为域偏移证据；重点放在冻结头校准后的校准迁移 |
| 门控参数量超标 | 压缩不确定性 MLP 隐层；保留门控核心，去掉冗余全局路通道 |
| 统计检验不显著 | 报告效应量与 Bootstrap CI，不伪造显著性 |
| 复现偏差 >1.5% | 先检查放大倍数分组、染色归一化、患者级划分解析，再改模型 |
| 外部验证掉点过多 | 讨论域偏移来源（尺度、染色、采集协议），不回避 |

## 十一、预期成果

1. 一套可复现的 BreakHis 患者级二分类评估流水线，包含患者级五折划分生成、无泄漏校验、统一指标与统计检验脚本。
2. 一个不确定性门控的轻量双路病理分类原型，在参数量约束下进入患者级 92%—96% 合理区间，并提供决策一致的门控解释。
3. 一份 BACH 两阶段外部验证与跨域校准分析，明确内生不确定性门控与 post-hoc 温度缩放的差异。
4. 一篇方法清晰、实验严谨、可投稿 SCI 期刊的论文初稿。
